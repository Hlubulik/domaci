# Příprava pro cvičení 2

Rozbalte celý ZIP do pracovní složky. Obsahuje tři vzorová CSV,
úplné kontrolní skripty Pythonu a MATLABu a notebook pro Colab.
Virtuální prostředí ani řešení hodnoceného úkolu neobsahuje.

- `mereni_teploty.csv`: 241 řádků, hlavička `t,T`, čas v s a teplota v °C.
- `kody_dilu.csv`: zdroj pro společný experiment v Excelu.
- `volny_pad_vzor.csv`: pouze náhradní data pro výuku. Hodnocený skript
  musí použít vlastní volný pád z domácí přípravy. Nezaměňte vzorová data
  s vlastními. Pro zkoušku na vzorových datech si vytvořte kopii
  `volny_pad.csv`; vlastní soubor před tím uchovejte mimo tuto složku.
- `kontrola_prostredi.py` / `.m`: spusťte ve složce s měřením teploty.
  Očekáváme kontrolní výpis a graf. Skripty se neodevzdávají.
- `kontrola_colab.ipynb`: otevřete v Colabu, nahrajte měření a spusťte
  buňky shora dolů. Není řešením hodnoceného úkolu.

Ve VS Code vyberte interpreter `.venv`; pro notebook se kernel vybírá
samostatně. V MATLAB Online nahrajte soubory a nastavte Current Folder.
Zdrojová CSV nepřepisujte, ani je neukládejte po otevření v Excelu.

Balíček sestaven 12. 10. 2026 ze zdrojů přednášky a cvičení 2.
